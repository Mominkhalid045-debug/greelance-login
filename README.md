# Greelance Auth & Form Flow

A pixel-perfect, responsive authentication and application flow for the Greelance platform built with React, Vite, and Tailwind CSS.

## Live Demo
Check out the live deployment on Vercel:
[https://greelance-project.vercel.app](https://greelance-project.vercel.app) (Reference link)

## Implemented Screens
1. **Role Selection** (`/`) - The split-screen homepage to choose your role (Freelancer, Employer, etc.)
2. **Login / Signup** (`/login`, `/signup`) - Authentication forms with social login options.
3. **Password Recovery** (`/forgot-password`, `/verify-otp`, `/new-password`) - Full floating-card flow.
4. **Step 1: Upload Resume** (`/form`) - The first step of the freelancer application.
5. **Step 2: Setup Profile** (`/setup-profile`) - The personal information form.

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the local development server

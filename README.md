# Greelance Login Page

A pixel-perfect, responsive login page for the Greelance platform built with React and Tailwind CSS.

## Live Demo
Check out the live deployment on Vercel:
[https://greelance-login.vercel.app](https://greelance-login.vercel.app)

## Getting Started

1. Clone the repository
2. Run `npm install`
3. Run `npm run dev` to start the development server
